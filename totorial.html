1. blockquote Tag

The blockquote tag is used to display a long quotation from another source. It is displayed in a separate block.

Example:

Success is not final, failure is not fatal: it is the courage to continue that counts.

2. q Tag

The q tag is used for a short quotation inside a normal sentence. The browser will add quotation marks automatically.

Example:

My teacher said Practice makes perfect during our last lesson.

3. pre Tag

The pre tag is used to display text exactly as it is written, including spaces and line breaks. It is mostly used to display code.

Example:

Conclusion

blockquote is for long quotes, q is for short quotes, and pre is for displaying code.
